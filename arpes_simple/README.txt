Обробка ARPES-спектрів (U-Net, LinkNet, DeepLabV3)

Встановлення і запуск:
    pip install -r requirements.txt
    pip install -r requirements-optional.txt    (необов'язково: h5py для файлів .h5)
    python main.py

Моделі: покладіть файли unet.onnx, linknet.onnx, deeplabv3.onnx у папку models/.
Якщо файлу немає, програма під час першого запуску моделі запропонує вказати його вручну.

Порядок роботи:
    1. «Відкрити файл…» — спектр (рядки — енергія, стовпці — імпульс). Формати: CSV, TXT, DAT, NPY, NPZ, HDF5 (.h5), MATLAB (.mat),
       PNG, JPG, TIFF, BMP. Для тривимірних даних береться перший зріз. Для перевірки є sample_spectrum.csv.
    2. Оберіть модель.
    3. «Передбачити» — ліворуч спектр, праворуч окремий графік знайденої кривої.
       Розрахунок іде вікнами 128×128 з кроком 8 пікселів, тому на великих спектрах може тривати до хвилини
       (кнопка в цей час показує «Триває розрахунок…»). Спектр розміром 128×128 і менший доповнюється до потрібного розміру.
    4. Повзунок змінює поріг без повторного запуску мережі.
    5. «Зберегти» — записує криву (CSV) і обидва графіки (PNG).

Файли: main.py — вікно, model.py — підготовка спектра й пошук кривої,
       onnx_predict_module.py — модуль передбачення: нарізає спектр на вікна, запускає ONNX-модель, склеює карту ймовірностей.
       Для U-Net і LinkNet використовується predict_band, для DeepLabV3 — predict_band_deeplab (інший формат входу й виходу).

Запуск подвійним кліком: ARPES_run (Windows). Під час першого запуску створює папку .venv (шукає Python 3.11, 3.12, 3.10 або 3.9),
встановлює залежності й запускає main.py. Наступні запуски швидші: .venv уже є.
Якщо встановлення не вдалося, вікно консолі залишається відкритим із текстом помилки, а зламана папка .venv видаляється.
Найнадійніше працює Python 3.11 або 3.12 (на 3.13 і новіших деякі пакети можуть не встановитися).
